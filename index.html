Mapping Rules

  • Mapping Review 的來源是 Test Excel 內已填寫的 Change Command，不由 Baseline 推導 Suggested Change Command。
  • Converted Data 以 Test Excel Original Data 為起點，依 User Accept 的 Change Command 執行轉換。
  • Change Command 空白代表沒有 Mapping 指令，不因 Baseline 差異自動建立 Rename / Merge。
  • User 可 Accept、Edit 或 No Change；所有有 Change Command 的項目都完成 Review 後才可 Confirm Mapping。
  • Merge 為 level-aware / subtree-aware，不另設 Move。
  • PDL 不做 physical Delete；MD Delete 為特殊轉換，不可 cascade physical delete。
  • 括號 PDL 為 Upcoming Phase Out annotation，不產生 Mapping Change Log。
  • Baseline 為獨立資料集，本版不參與 Mapping Review、Command 判斷或 Converted Data 產生。
