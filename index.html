Mapping Rules

  • Change Command 一律來自 Test Excel（或 User Edit），Baseline 不自行推導指令。
  • Baseline 僅用於 Batch Validation：判斷同 Level Target 在 Online Baseline 是否已存在。
  • Single Source → New Target 應為 Rename；Target 已存在應為 Merge。
  • Multiple Sources → Same New Target = Case 3，必須由 User 指定 Primary Source；Primary = Rename，其餘 = Merge。
  • Converted Data 以 Test Original Data 為起點，只執行 User Accept 後的最終 Command。
  • 空白 Change Command 不建立 Mapping Review。
  • Merge 為 level-aware / subtree-aware，不另設 Move。
  • PDL 不 physical Delete；MD Delete 為特殊轉換。
