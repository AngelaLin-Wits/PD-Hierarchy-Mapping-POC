Mapping Rules

  • Change Command 主要來自 Test Excel；Baseline 不自行推導。
  • Baseline 只做 Case 1/2/3 規則驗證。
  • Case 3 依 Sheet + Level + Target 分組；Primary Source 直接在該組 Mapping Review 第一列設定。
  • Primary Source 只能從該組 Sources 選擇；選定後產生 1 Rename + 其餘 Merge，狀態仍為 Pending Review。
  • Accept 後立即套用到 Converted Data；Confirm Mapping 是整批最終確認與正式 Log/Export。
  • Converted Data 可用 + Add Hierarchy 新增 MD / PD / PDL；系統建立 Add Change Command，仍需 Accept。
  • PD Head、MD Head、PG Head、Remark 暫不顯示、不參與 Mapping；Export 時保留原欄位與原值。
