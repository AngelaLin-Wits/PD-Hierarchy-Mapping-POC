Mapping Rules

  • Target 是否存在，一律以 immutable Online Baseline、相同 Level 判斷，不受 Excel 列順序影響。
  • Single Source → New Target = Rename；Target 已存在 = Merge；Multiple Sources → New Target 必須選 Primary Source。
  • 系統 Suggested Change Command 不等於 User Confirmation。每筆必須 Accept、有效 Edit，或明確 No Change。
  • No Change 不阻擋 Confirm Mapping，也不進正式 Mapping Change Log，但保留 Review Audit。
  • Merge 為 Level-aware / subtree-aware；父層 Merge 時其下階層一起處理，不另設 Move。
  • PDL 不 Delete，只能 Phase Out；MD Delete 為特殊轉換，不可 cascade physical delete。
  • 括號 PDL 視為 Upcoming Phase Out annotation，不產生 Mapping Change Log。
