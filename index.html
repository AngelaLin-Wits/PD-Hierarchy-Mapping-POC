Mapping Rules

  • Target 是否存在，一律以 immutable Online Baseline、相同 Level 判斷，不受 Excel 列順序影響。
  • Single Source → New Target = Rename；Target 已存在 = Merge；Multiple Sources → New Target 必須選 Primary Source。
  • Merge 為 Level-aware / subtree-aware；父層 Merge 時其下階層一起處理，不另設 Move。
  • PDL 不 Delete，只能 Phase Out；PD/PG 等沒有有效子節點時保留並視為 inactive/disabled。
  • MD 為唯一 Delete 特例，但 Delete MD 只是移除 MD 名稱/節點表示，不可 cascade delete 其他階層。
  • 括號 PDL 視為 Upcoming Phase Out annotation，不產生 Movement Log。
  • Change Command 可空白；系統產生 Suggested Change Command，須由使用者確認。
